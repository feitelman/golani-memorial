# גדוד 13 — קרבות 7 באוקטובר · אתר הנצחה ומפה טקטית

אתר חוויה קולנועי בעברית (RTL) המשלב **מפת קרב טקטית אינטראקטיבית**, **שחזור ציר זמן**, **פאנל סיפור קרב**, **קיר הנצחה** ו**לוח בקרה לניהול** — לקרבות גדוד 13 של חטיבת גולני בעוטף עזה.

התוכן מבוסס על תחקירי הקרבות, ופרטי הנופלים ותמונותיהם מאומתים מול אתר "יזכור" ואתר צה"ל.

## הרצה מקומית

```bash
npm install
cp .env.example .env.local   # ממלאים מפתחות (ראו למטה)
npm run dev                  # http://localhost:3000
```

**ללא מפתחות** האתר רץ במצב דמו: המפה עוברת ל"מצב סכמטי" (SVG טקטי) והנתונים נטענים מ-`lib/snapshot.json` — עותק של מסד הנתונים.

## משתני סביבה

| משתנה | תפקיד | בלעדיו |
| --- | --- | --- |
| `NEXT_PUBLIC_MAPBOX_TOKEN` | מפת Mapbox תלת־ממד | מפה סכמטית SVG |
| `NEXT_PUBLIC_SUPABASE_URL` / `_ANON_KEY` | קריאת נתונים | קריאה מה-snapshot |
| `SUPABASE_SERVICE_ROLE_KEY` | שמירת עריכות מהאדמין (שרת בלבד) | אדמין במצב דמו |
| `ADMIN_PASSWORD` / `ADMIN_SESSION_SECRET` | כניסה ללוח הבקרה | `/admin` נעול |

## Supabase

1. צרו פרויקט ב-[supabase.com](https://supabase.com).
2. הריצו את `supabase/schema.sql` ב-SQL editor. את התוכן מוסיפים דרך `/admin` (או משחזרים מגיבוי — ראו "גיבוי ושחזור").
3. מלאו את משתני הסביבה.

הסכימה כוללת RLS לקריאה ציבורית; כתיבה רק דרך ה-service-role במסלול ה-API של האדמין.

## ניהול תוכן

**מסד הנתונים הוא מקור האמת היחיד.** עורכים דרך `/admin`; כל שמירה נבדקת בשרת (שעות, מיקומים, שדות חובה) ונשמרת בלי סיכון למחיקה — שמירה שנכשלת לא מוחקת דבר.

| פקודה | מה עושה |
| --- | --- |
| `npm run import-battles -- file.json` | בודק קרבות מקובץ JSON (ריצת ניסיון). עם `--yes` — שומר. לא נוגע בקרבות שאינם בקובץ. |
| `npm run snapshot` | מעדכן את `lib/snapshot.json` מהמסד (משמש רק במצב דמו). אותו פורמט מתאים ל-import. |

## מצב טקס / עמדת תצוגה

למסך גדול באירוע: `/map?mode=kiosk` — מסך פתיחה עם כפתור "הפעלה במסך מלא", ואז
הסיור רץ לבד על כל המוקדים בלולאה: כרטיס פתיחה לכל מיקום, התחנות (כל פאנל נגלל
לבד), שמות הנופלים של המיקום, וכרטיס סיום. Esc — יציאה.

- `&loc=מחנה מעבר ארז` — לולאה על מיקום אחד בלבד.
- `&autostart=1` — בלי מסך פתיחה (לדפדפן שכבר במצב קיוסק/מסך מלא).
- המסך לא נכבה בזמן ההרצה. המפה עצמה צריכה אינטרנט (אריחי Mapbox).

## גיבוי ושחזור

כל לילה GitHub Action מגבה את כל הטבלאות ואת כל הקבצים (תמונות/הקלטות) לענף `backups` — כל לילה הוא נקודת שחזור.

| פקודה | מה עושה |
| --- | --- |
| `npm run backup -- dir` | גיבוי מלא לתיקייה |
| `npm run restore -- dir` | שחזור (ריצת ניסיון). עם `--yes` — משחזר. לא מוחק דבר. |
