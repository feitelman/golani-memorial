# גדוד 13 — קרבות 7 באוקטובר · אתר הנצחה ומפה טקטית

אתר חוויה קולנועי בעברית (RTL) המשלב **מפת קרב טקטית אינטראקטיבית**, **שחזור ציר זמן**, **פאנל סיפור קרב**, **קיר הנצחה** ו**לוח בקרה לניהול** — לקרבות גדוד 13 של חטיבת גולני בעוטף עזה.

> ⚠️ התוכן הנוכחי הוא **דמו להמחשה**. המיקומים אמיתיים, אך תיאורי הקרבות ושמות הלוחמים הם דוגמאות בלבד ומיועדים להחלפה בחומר מאומת דרך לוח הבקרה.

## הרצה מקומית

```bash
npm install
cp .env.example .env.local   # אופציונלי — האתר רץ גם בלי מפתחות
npm run dev                  # http://localhost:3000
```

**ללא מפתחות** האתר עובד מלא: המפה עוברת ל"מצב סכמטי" (SVG טקטי) והנתונים נטענים מ-`lib/seed-data.ts`.

## משתני סביבה

| משתנה | תפקיד | בלעדיו |
| --- | --- | --- |
| `NEXT_PUBLIC_MAPBOX_TOKEN` | מפת Mapbox תלת־ממד | מפה סכמטית SVG |
| `NEXT_PUBLIC_SUPABASE_URL` / `_ANON_KEY` | קריאת נתונים | קריאה מ-seed |
| `SUPABASE_SERVICE_ROLE_KEY` | שמירת עריכות מהאדמין (שרת בלבד) | אדמין במצב דמו |

## מסך מול קובץ

| עמוד | נתיב | תיאור |
| --- | --- | --- |
| בית | `/` | אינטרו קולנועי + כניסה |
| מפה | `/map` | מפת תלת־ממד, ציר זמן, פילטרים, פאנל קרב, סאונד |
| הנצחה | `/memorial` | קיר הנצחה עם חיפוש |
| אודות | `/about` | הקשר ומקורות |
| אדמין | `/admin` | ניהול קרבות, ציר זמן, נופלים ומדיה |

## Supabase

1. צרו פרויקט ב-[supabase.com](https://supabase.com).
2. הריצו את `supabase/schema.sql` ואז `supabase/seed.sql` ב-SQL editor.
3. מלאו את משתני הסביבה.

הסכימה כוללת RLS לקריאה ציבורית; כתיבה רק דרך ה-service-role במסלול ה-API של האדמין.

## טכנולוגיה

Next.js 14 (App Router) · TypeScript · TailwindCSS · Framer Motion · Mapbox GL JS · Three.js · Supabase.

## עיצוב

שחור־לבן קולנועי, אקצנט אדום־כהה בשימוש מינימלי (מצב פעיל/נופלים בלבד), HUD טקטי עם רטיקל פינתי, גריין, סקאנליין ו־vignette. גופן Heebo (עברית) + IBM Plex Mono (קואורדינטות/שעות). תומך `prefers-reduced-motion`.
